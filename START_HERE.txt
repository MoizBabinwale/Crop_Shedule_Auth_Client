🎯 WHAT WAS RESTORED:

   Google OAuth Login:
   └─ Users can now sign in with their Google account
   └─ Requires backend: POST /auth/google-login endpoint
   └─ Returns: JWT token + Google access token

   Calendar Synchronization:
   └─ When quotations are created, dates sync to Google Calendar
   └─ Creates events for each farm schedule week
   └─ Requires backend: POST /calendar/sync-events endpoint
   └─ Gracefully handles if sync fails

   Google Token Management:
   └─ Google access tokens stored in sessionStorage
   └─ Tokens cleared on user logout
   └─ Conditional features based on Google authentication
